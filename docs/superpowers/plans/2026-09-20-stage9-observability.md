# Этап 9 — Observability: Implementation Plan

**Goal:** Дать возможность понять, что происходит с системой под нагрузкой,
не создав при этом канала утечки тайны голосования.

**Spec:** roadmap, этап 9; ТЗ п.61, 62, 63, 64.

---

## Global Constraints

1. **Телеметрия не должна раскрывать выбор студента (ТЗ п.4, 63).**
   Ни в логах, ни в метриках, ни в трейсах не должны встречаться вместе
   `student_id` и `candidate_id`. Это не «нежелательно» — это разрушает
   главный инвариант системы.
2. **Кардинальность метрик ограничена.** Метка со значением `UUID` порождает
   отдельный временной ряд на каждое значение: путь `/elections/<uuid>/`
   как метка убил бы Prometheus за сутки.
3. **Метрики не публичны.** `/metrics` раскрывает внутреннее устройство
   и объёмы; наружу он не выставляется.
4. **Наблюдение не должно замедлять голосование.** Никаких синхронных
   отправок по сети в горячем пути.
5. **411 тестов остаются зелёными.**

---

## Задачи

### 1. Structured JSON logging (ТЗ п.61)
- Формат: одна строка JSON на событие; `request_id`, метод, **маршрут**
  (а не путь с подставленными id), статус, `duration_ms`, имя инстанса.
- Явный список запрещённых полей: `Authorization`, пароль, OTP,
  выбор кандидата, тело `POST /vote`.
- Фильтр, вырезающий их, даже если кто-то попробует залогировать.

### 2. Метрики (ТЗ п.62)
- HTTP: количество, длительность (гистограмма для p50/p95/p99),
  коды ответов, запросы в работе.
- Голосование: попытки, успехи, `already_voted`, ошибки.
- База: длительность запросов, ошибки.
- Кэш: попадания, промахи, ошибки.
- Метка маршрута — только шаблон URL.

### 3. Приватность метрик (ТЗ п.63)
- `successful_votes_total{election_id}` допустим.
- `candidate_id` меткой **не используется**: он и кардинальность
  раздувает, и вместе с временем голосования сужает круг подозреваемых.
- Тест, обходящий весь реестр метрик и проверяющий отсутствие
  запрещённых меток.

### 4. Трейсинг (ТЗ п.64)
- Готовность к OpenTelemetry без обязательной зависимости:
  конфигурация и правила семплирования описаны, включение опционально.
- Явно задокументировано, что не должно попадать в спаны.

---

## Definition of Done

- [ ] Логи в JSON, с `request_id` и маршрутом вместо пути.
- [ ] Ни `Authorization`, ни OTP, ни тело `POST /vote` в логи не попадают —
      проверено тестом.
- [ ] Метрики покрывают HTTP, голосование, базу и кэш.
- [ ] Ни одна метрика не содержит идентификатор студента.
- [ ] `student_id` и `candidate_id` нигде не встречаются вместе.
- [ ] Кардинальность ограничена: метка — шаблон маршрута.
- [ ] `/metrics` не доступен публично.
- [ ] Правила семплирования и запреты для трейсинга задокументированы.
