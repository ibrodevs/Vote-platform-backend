# Этап 8 — Security hardening: Implementation Plan

**Goal:** Закрыть D-05 (OTP в открытом виде), гонку при проверке OTP и ввести
rate limiting, который не блокирует тысячи студентов за одним NAT.

**Spec:** roadmap, этап 8; ТЗ п.34, 35, 36, 67, 97, 98.

---

## Global Constraints

1. **Rate limiting не должен блокировать университет.** За одним внешним IP
   могут сидеть 5000 студентов (ТЗ п.36). Ключ для `/vote` — студент, не IP.
2. **Нагрузочные тесты этапа 10 не должны упираться в лимиты** — пороги
   настраиваются окружением и отключаются для бенчмарка.
3. **Контракт не меняется**, 385 тестов остаются зелёными.
4. **OTP не должен попадать никуда, кроме SMS-шлюза** (ТЗ п.34).

---

## Задачи

### 1. D-05: хэш OTP вместо открытого текста (ТЗ п.34)
- `StudentAuthSession.code` → `code_hash`; сверка по хэшу.
- Код не появляется в `__str__`, логах, `print`, ответах и APM.
- Миграция: существующие сессии живут минуты, их можно просто обнулить,
  но **сделать это явно**, а не потерять молча.
- Demo-режим: код возвращается в ответе только при `DEBUG=True`.

### 2. Гонка при проверке OTP (ТЗ п.35)
- `attempts += 1; save()` заменяется на атомарный `F('attempts') + 1`.
- Один OTP не может быть успешно использован дважды параллельно:
  условный `UPDATE ... WHERE is_verified = false` вместо чтения и записи.

### 3. Rate limiting (ТЗ п.36)
- Разные политики: строгая для аутентификации, отдельная для голосования.
- Для `/vote` ключ — идентификатор студента; IP используется только там,
  где студента ещё нет (логин, регистрация, OTP).
- Пороги из окружения; выключаются целиком для нагрузочных тестов.

### 4. Вход администратора (ТЗ п.67, 98)
- Проверить, что ответы при неверном email и неверном пароле неразличимы.
- Django admin: отдельный путь из окружения, по умолчанию закрыт.

---

## Definition of Done

- [ ] OTP хранится хэшем; в логах, `__str__` и ответах его нет.
- [ ] Demo-OTP невозможен в production (проверяется `production_check`).
- [ ] Параллельная проверка одного OTP не даёт двух успешных входов.
- [ ] `attempts` инкрементируется атомарно.
- [ ] Rate limiting: строгий на аутентификацию, по студенту на голосование.
- [ ] 5000 студентов за одним IP не блокируют друг друга — тест.
- [ ] Лимиты отключаемы для нагрузочного тестирования.
- [ ] Путь Django admin задаётся окружением.
